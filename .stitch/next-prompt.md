# LPG Cylinder Catalogue & Inventory Moderation Console

Design an administrative catalogue management screen for LPG gas cylinder brands, variants, and branch stock.

**DESIGN SYSTEM (REQUIRED):**
- Primary Color: Deep Navy (`#003496`), Safety Flame Orange Accent (`#FF6600`)
- Background: `#F8FAFC` (Slate 50), Surface: Clean White `#FFFFFF`, Borders: Slate 200 `#E2E8F0`
- Typography: Inter font, crisp contrast, tabular numbers for currency and stock counts

**Key Sections:**
1. Top Category & Brand Selector (Beximco, Omera, Bashundhara, Jamuna, TotalGas).
2. Cylinder Variant Matrix:
   - Variant Types: `12kg Refill`, `12kg Package (New Cylinder)`, `35kg Commercial`, `45kg Industrial`.
   - Pricing Grid: Base Refill Price, Empty Cylinder Deposit (Paisa/BDT), Admin Margin.
3. Branch Inventory Level Alerts:
   - Low stock warning pills (<10 cylinders remaining).
4. Compliance & Moderation Action:
   - Price adjustment verification and trade standard compliance approval.
